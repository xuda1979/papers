\markboth{后记}{后记}

写完这本书的最后一个字，窗外已是深夜。

回顾过去一年的写作历程，最大的感受仍是“紧迫”。每当以为某个章节已经可以定稿，新的模型能力、新的政策动向、新的行业信号又会刷新问题的边界。写作者追赶不了日更的新闻，但可以尽量追到那些更慢、却更决定性的结构性因素——算力、生态、人才与制度。

如果要用一句话概括本书的意图，我更愿意这样表达：把大模型放回"国家能力建设"的坐标系中去看待。它既可能成为效率与创新的放大器，也可能因为外部依赖、供应链脆弱或治理缺位而转化为系统性风险。

我仍然保留“\,\,不响的原子弹\,\,”这个比喻，但它在这里更多是一种提醒：影响不会像爆炸那样显眼，却可能以日常工具链、知识生产与组织流程的方式积累，最终以复利效应拉开差距。对于这种变化，最难也最重要的是提前建设“可持续的能力体系”，而不是在短期热度中反复摇摆。

作为一名科研工作者，我深知本书的局限：许多细节依赖公开材料，许多判断也带有个人视角。但我仍希望它能起到一点作用——把问题说清楚，把可操作的选项摆出来，促成更扎实、更基于证据的讨论。

如果本书能让读者在面对下一次"新模型发布""新政策出台"时，不只停留在惊叹或焦虑，而是能回到这些更基础的问题：我们缺的究竟是什么、该先补哪一块、怎么评估成效——那这本书就没有白写。

\subsection*{五年回看校验清单}

\textit{本书写于2026年初。无论你在何时读到这些文字，以下七个问题可以帮助你检验书中判断的有效性，也帮助你评估形势的最新进展。}
\begin{enumerate}
    \item \textbf{算力自主化进展如何？}国产AI芯片在智算中心的部署比例是否显著提升？软件生态（类CUDA框架）是否初步建成？——如果答案是肯定的，第一章和第五章关于"认知基础设施"建设的判断方向正确；如果进展缓慢，则供应链风险可能比本书预估的更为严峻。
    
    \item \textbf{中美模型能力差距是扩大还是缩小？}以推理能力、多模态能力和Agent能力三个维度衡量，国产头部模型与美国头部模型的差距是6个月以内还是12个月以上？——差距缩小验证了"效率优先路径"的可行性；差距扩大则需要重新审视第七章的投入建议。
    
    \item \textbf{AI for Science是否产生了可验证的重大科学发现？}是否有AI主导或深度参与的研究成果获得了诺贝尔级别的认可？自动化实验室是否从原型走向了常态化运行？——如果是，第八章关于"科研主权"的判断正在兑现。
    
    \item \textbf{AI安全事故是否已经发生？}是否出现过因基础模型漏洞导致的大规模安全事件、因深度伪造引发的重大政治或金融危机、或因AI系统故障引发的关键基础设施事故？——如果已经发生，第四章和第十二章的风险预警价值将被验证；如果尚未发生，仍不可放松，因为"尚未发生"不等于"不会发生"。
    
    \item \textbf{AGI进展处于什么阶段？}参照第十一章的"认知能力阶梯"，当前最强模型处于哪一级？是否已经出现能够自主进行科学研究或自我改进的AI系统？——这个问题决定了本书中"长期"部分的建议是否需要提前到"中期"执行。
    
    \item \textbf{人才竞争态势如何？}中国AI顶尖人才的净流入还是净流出？第九章建议的人才吸引机制是否落地？国内AI研究的国际影响力是否提升？——人才是所有其他能力的根基，这个指标最能反映综合竞争力的变化方向。
    
    \item \textbf{治理框架是否建立？}《人工智能法》是否已经出台？AI安全测评体系是否运转？国际AI治理合作是否有实质性进展？——治理能力是"能力体系"的最后一块拼图，缺了它，技术能力再强也可能失控。
\end{enumerate}

\noindent 如果五年后（2031年），上述七个问题中有四个以上的答案是积极的，那么我们在“超级智能时代”的早期战役中已稳固阵地。如果多数答案是消极的，那将意味着我们在人类最具决定性的技术革命中遗憾出局。

\subsection*{给未来的留白：最终的战略忠告}

大国博弈不相信眼泪，技术的代差碾压也从不给人喘息之机。大模型不仅仅是科技树上的一个分支，而是整个科技树的“根系”。我将其称为**“不响的原子弹”**与**“认知世界的新造物主”**。在这场竞赛中：
\begin{itemize}
    \item \textbf{最大的危险是“失去想象力”}。用过去互联网或信息化的眼光来看待AGI的未来，就会在战略规划中总是慢人半拍。
    \item \textbf{最大的错误是“过度防御”}。在未掌握最高点之前，所有的防守都是脆弱的；唯一的防御就是比对手发展得更快，比对手的模型拥有更深邃的认知维度。
    \item \textbf{最大的机遇是“举国统筹的制度优势”}。自由市场可能会涌现实时创新，但建立超级基础设施、集中调度能源与算力，正是体制的长处所在。我们必须激活这种力量，将其导向“人类认知边界的拓荒”。
\end{itemize}

无论未来风云如何变幻，掌握这一核心能力，不仅是保障国家安全的基石，更是定义未来人类文明版图的唯一凭证。\textbf{不要问未来是什么样，要去创造未来。}
