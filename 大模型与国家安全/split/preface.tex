\markboth{序言}{序言}

我们正站在一个重要的技术转折点上。

2025年12月，当我写下这些文字时，大模型技术仍在以超预期的速度演进：推理能力的提升、工具调用能力的成熟、多模态生成的普及，正在把AI从“能协助”推向“能承担”。与此同时，围绕算力、资本与规则的竞争正迅速升级。美国宣布的5000亿美元“创世纪计划”（Stargate Project），更像是一场国家层面的基础设施动员——它提醒我们，前沿能力的差距不再只是企业之间的赛跑，而正在转化为制度、资源与工程体系层面的长期竞争。

大型语言模型（Large Language Models，LLMs）的出现，标志着人工智能从“专项任务能力”迈向“通用认知能力供给”。从2022年底ChatGPT引发全球关注，到如今推理模型、智能体与多模态应用快速扩散，时间跨度并不长。对后来者而言，真正稀缺的不是概念，而是可持续投入、可复用扩散的能力体系；至于“还剩三到五年窗口”这类判断，本书更愿意把它当作一种警示性的时间刻度，而不把它当作精确预测。

作为一名长期从事AI for Science与大模型研究的科研工作者，我希望把这些年的观察与思考整理成更可讨论、也更可检验的判断。本书不是单纯的技术著作，也不是情绪化的时评，而是一份带着问题意识的政策研究：我尝试从国家能力的角度，梳理大模型对科研、产业、治理与安全的影响机制，指出竞争格局中的关键约束，并提出可落地的政策选项。

本书最核心的观点是：\textbf{大模型正在成为一种新的国家级“认知基础设施”}。我借用“21世纪\,\,不响的原子弹”的比喻，是为了强调其影响的隐蔽性与持续性：核武器更多体现为威慑，使用与否可形成明确边界；而认知能力的差距一旦嵌入科研、教育、产业与治理流程，会以日常使用的方式积累，并可能通过规模与复利效应被放大。

这一判断当然可能引发不同意见。技术革命的关键节点上，最难的是把讨论从“热闹”拉回“结构”：哪些能力必须掌握在自己手里？哪些环节可以合作？哪些短板需要用制度、投入与组织方式去补齐？我写这本书的目的，是把这些问题摆到台面上。

为了使本书的讨论能够穿越技术迭代的周期，我在开篇明确提出以下**未来十年的全新深刻预测与结构性判断**，它们构成了全书的理论骨架与战略指导：

\textbf{四大前瞻性趋势预测：}
\begin{enumerate}[label=(\arabic*)]
    \item \textbf{智能的极化与阶层固化}：未来的国家和企业将被划分为“模型创造者”与“API调用者”。如果核心认知基础设施不自主，一个国家的产业数字化将沦为为他人贡献数据的“数字劳工”。
    \item \textbf{“幽灵化”的国家级对抗}：大国竞争将从物理空间的威慑，转移到认知空间、合成数据与智能体代理层面的隐匿博弈。没有强大算力与高阶模型的国家，在遭遇算法操纵时将完全失去战场感知与招架之力。
    \item \textbf{算力—能源复合体成为新“石油”}：未来评判国家实力的指标将是“算力密度”与“能源转化智能的效率”。算力中心不再只是IT设施，而是最高级别的战略资源与工业心脏。
    \item \textbf{科学研究的范式奇点（AI for Science 2.0）}：诺贝尔奖级别的发现将越来越多地由AI主导生成。在材料、生物、军工领域的研发周期将被压缩数倍，失去这一工具的国家将被永久性地甩出科技第一梯队。
\end{enumerate}

\textbf{全书的核心战略指导原则：}
大国博弈的本质在于：谁能最先以举国体制构建可控的超级智能（AGI）。
\begin{enumerate}[label=(\arabic*)]
    \item \textbf{超越热度，聚焦底层}：放弃零散的“表层应用创新”，将至少80\%的战略资源聚焦于芯片核心工艺、高质量数据集、底层模型架构、以及能耗供给这几大硬核领域。
    \item \textbf{敏捷治理与以攻代守}：安全不应是限制发展的枷锁。要在“战争中学习战争”，用最先进的AI对抗AI，用发展解决安全问题。
    \item \textbf{构建国家级统筹与军民融合机制}：打破“各立山头”的现状，像“曼哈顿计划”与“两弹一星”一样建立国家级大模型统筹工程体系。
\end{enumerate}

希望本书不仅仅是对当下技术的一次梳理，更希望能成为一份\textbf{指引我们在“超级智能时代”前夜生存与突围的战略指南}，为决策者、研究者与广大产业界提供一个真正具有前瞻视角的行动框架。
