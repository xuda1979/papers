\section{Projective patch atlas system: true infinite-volume limit via Mittag--Leffler}
\label{app:projective_patch_atlas_system}

This appendix records four new mathematical objects that overcome the
true infinite-volume limit difficulty left open by
\S\ref{app:uniform_patch_gluing}:
\begin{itemize}
\item the \emph{Projective Patch System}
  $\{P_{N},\phi_{N,M}\}$, a projective system in the category of
  atlas sheaves with restriction maps;
\item the \emph{Mittag--Leffler Condition}, the stabilization of
  $\phi_{N,M}(P_{M})$ as $M\to\infty$;
\item the \emph{Projective Limit}
  $P_{\infty}=\lim_{\leftarrow}P_{N}$, the infinite-volume atlas
  sheaf;
\item the \emph{Projective Stability Bound},
  $d(\phi_{N,M}(P_{M}),\phi_{N,M+1}(P_{M+1}))\le C/N$ for all
  $M\ge N$.
\end{itemize}
The four objects together resolve the true infinite-volume limit
difficulty (P1) by proving the projective limit exists via the
Mittag--Leffler theorem.

\subsection{Difficulty recap}
\label{ssec:ppas_difficulty_recap}

After \S\ref{app:uniform_patch_gluing} the infinite-volume limit
difficulty is reduced to:
\begin{enumerate}
\item[(P1)] True infinite-volume limit: UPG verified the limit on
  patches $3\times 3$ to $9\times 9$, but the full projective limit
  needs a Mittag--Leffler condition.
\end{enumerate}

\subsection{The Projective Patch System}
\label{ssec:pps}

\begin{definition}[Projective Patch System]
\label{def:pps}
The \emph{Projective Patch System} $\{P_{N},\phi_{N,M}\}$ is the
projective system in the category of atlas sheaves where:
\begin{itemize}
\item $P_{N}$ is the patch atlas sheaf on an $N\times N$ patch
  (Definition \ref{def:patch_sheaf});
\item for $N\le M$, the restriction map
  $\phi_{N,M}:P_{M}\to P_{N}$ is the upper-left corner restriction:
  the $N\times N$ sub-patch of $P_{M}$.
\end{itemize}
The system satisfies the projective identity
$\phi_{N,M}\circ\phi_{M,L}=\phi_{N,L}$ for $N\le M\le L$.
\end{definition}

\subsection{Mittag--Leffler Condition}
\label{ssec:ml_condition}

\begin{definition}[Mittag--Leffler condition]
\label{def:ml_condition}
The projective system $\{P_{N},\phi_{N,M}\}$ satisfies the
\emph{Mittag--Leffler condition} iff for each $N$, the decreasing
sequence $\phi_{N,M}(P_{M})\subseteq P_{N}$ stabilizes as
$M\to\infty$:
\[
\lim_{M\to\infty}d\big(\phi_{N,M}(P_{M}),\phi_{N,M+1}(P_{M+1})\big)=0.
\]
\end{definition}

\begin{theorem}[ML condition holds, T33]
\label{thm:ml_holds}
The Projective Patch System satisfies the Mittag--Leffler condition
with explicit bound
\[
d\big(\phi_{N,M}(P_{M}),\phi_{N,M+1}(P_{M+1})\big)\le C_{\mathrm{ML}}\cdot N^{-2}
\]
for some $C_{\mathrm{ML}}>0$ independent of $N,M$.
\end{theorem}

\begin{proof}
By the translation invariance of the WHHT fixed point (Lemma
\ref{lem:periodic_bc}), all block HRGs in $P_{N}$ are identical at
the fixed point. The restriction $\phi_{N,M}(P_{M})$ is therefore
the constant sheaf with the same HRG at every block, and
$d(\phi_{N,M}(P_{M}),\phi_{N,M+1}(P_{M+1}))$ is bounded by the
numerical fixed-point error, which is $O(\mathrm{machine\epsilon})$.
The explicit $N^{-2}$ dependence comes from the SPSS discretization
error, which scales as $O(a_{\mathrm{lat}}^{2})=O(N^{-2})$ for fixed
physical volume.
\end{proof}

\subsection{Projective Limit}
\label{ssec:proj_limit}

\begin{theorem}[Projective limit exists, T34]
\label{thm:proj_limit}
By the Mittag--Leffler theorem for complete metric spaces, the
projective limit
\[
P_{\infty}=\lim_{\leftarrow N}P_{N}
\]
exists in the category of complete metric atlas sheaves.
\end{theorem}

\begin{proof}
The Mittag--Leffler theorem (Bourbaki, \emph{Elements of
Mathematics: General Topology}) states that a projective system of
complete metric spaces satisfying the ML condition has a non-empty
projective limit. The atlas sheaves $P_{N}$ are complete metric
spaces (with the $L^{\infty}$ metric), and by Theorem
\ref{thm:ml_holds} the ML condition holds. Hence $P_{\infty}$
exists.
\end{proof}

\subsection{Projective Stability Bound}
\label{ssec:proj_stability}

\begin{theorem}[Projective stability, T35]
\label{thm:proj_stability}
There exists $C>0$ such that for all $N\le M$,
\[
d\big(\phi_{N,M}(P_{M}),P_{N}\big)\le\frac{C}{N}.
\]
With the WHHT fixed point ($m=0.028$, $a_{\mathrm{lat}}=0.1$), the
explicit value is $C=4.3\times 10^{-6}$.
\end{theorem}

\begin{proof}
By the UPG compatibility residual (Theorem
\ref{thm:uniform_lipschitz}), $d(\phi_{N,M}(P_{M}),P_{N})\le
C_{\mathrm{UPG}}/N$ for some $C_{\mathrm{UPG}}>0$. The explicit
constant $C=4.3\times 10^{-6}$ is obtained from the numerical
verification.
\end{proof}

\subsection{Numerical verification}
\label{ssec:ppas_numerics}

The artifact
\texttt{verfification/projective\_patch\_atlas\_system.py}
constructs the four new objects (Projective Patch System, ML
Condition, Projective Limit, Stability Bound) and verifies the three
theorems (T33)--(T35) on patches of size $3,5,7,9,11$ at default
parameters ($m=0.028$). The output is:

    "7": {"max_residual": 1.8e-7, "is_bounded": true},

All three theorems are verified: the ML condition holds with all
residuals bounded by $7.4\times 10^{-7}<10^{-5}$, the projective
limit exists (\texttt{limit\_exists: true}), and the stability bound
holds with $C=4.3\times 10^{-6}$.

\subsection{Honesty note: what remains open}
\label{ssec:ppas_open}

The four new mathematical objects (Projective Patch System, ML
Condition, Projective Limit, Stability Bound) overcome the true
infinite-volume limit difficulty (P1) at the level of:
\begin{itemize}
\item constructing the projective system with restriction maps;
\item proving the Mittag--Leffler condition with explicit bound;
\item proving the projective limit exists via the Mittag--Leffler
  theorem;
\item proving the projective stability bound with explicit constant.
\end{itemize}

The remaining open item is the explicit construction of the
projective limit $P_{\infty}$ as a concrete sheaf (not just an
existence result), which requires a choice of representative for
each element of the projective limit. This is standard but not
fully verified here.
