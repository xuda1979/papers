\section{Certificate Index and Audit Trail}
\label{sec:certificate-index}

This appendix summarizes the machine-checkable artifacts that support the intermediate-coupling bridge and the auxiliary analytic handshakes.
All numeric values appearing in the summary tables are loaded from the auto-generated file \texttt{verification\_results.tex} via the inclusion in \texttt{main.tex}.

\subsection{Logical steps and corresponding artifacts}

\begin{enumerate}
    \item \textbf{Ab initio constant derivation (non-circular inputs).}
    
    \textit{Claim.} The pollution/geometry constants entering the RG tail inequalities are derived from lattice geometry and group integrals, not assumed from the gap.

    \textit{Artifact.} \texttt{verification/rigorous\_constants\_derivation.py} producing \texttt{verification/rigorous\_constants.json}.

    \item \textbf{Strong-coupling handshake point.}

    	extit{Claim.} The Phase~2 verification includes audited checkpoints (see \texttt{split/verification\_results.tex}) and reports status via the corresponding per-$\beta$ macros (e.g. \texttt{\textbackslash VerStatusAtZeroPointFourZero}).

    \textit{Artifact.} \texttt{verification/export\_results\_to\_latex.py} generates \texttt{split/verification\_results.tex}.

    \item \textbf{Intermediate bridge (tube contraction).}

    \textit{Claim.} The RG tube contraction is certified throughout $\beta \in [\VerBetaStrongMax,\VerBetaIntermediateMax]$ with global status \textbf{\VerStatus}.

    \textit{Artifact.} \texttt{verification/full\_verifier\_phase2.py} (and supporting modules) as executed by \texttt{verification/run\_full\_audit.ps1}.

    \item \textbf{Lorentz/isotropy restoration (anisotropy trajectory).}

    \textit{Claim.} The anisotropy Jacobian remains strictly positive along the certified trajectory, ensuring invertibility (Implicit/Inverse Function Theorem).

    \textit{Artifact.} \texttt{verification/verify\_lorentz\_restoration.py} producing \texttt{verification/certificate\_anisotropy.json}.
\end{enumerate}

\subsection{Reproducibility contract (one command)}

On Windows, the full audit entrypoint is \texttt{verification/run\_full\_audit.ps1}. A run is considered successful if it exits with code 0 and the generated macros include \texttt{\string\newcommand\{\string\VerStatus\}\{PASS\}}.
