FMIC Submission Package

Prepared on: 2026-04-04
Target journal: Frontiers of Mathematics in China

Contents

- `pi.pdf`: final compiled manuscript PDF
- `pi.tex`: manuscript source with embedded bibliography
- `COVER_LETTER_FMIC.txt`: cover letter draft
- `SCHOLARONE_FMIC_METADATA.txt`: ScholarOne metadata draft
- `FMIC_SUGGESTED_REVIEWERS.txt`: optional reviewer suggestions
- `FMIC_SUBMISSION_CHECKLIST.md`: local submission checklist

Notes

- The manuscript compiles locally with `pdflatex`.
- The current compiled PDF is 42 pages.
- The bibliography is embedded directly in `pi.tex`, so no `.bib` file is needed for this package.
- `ems-journal.sty` is present in the working directory but is not used by `pi.tex`.

Suggested upload/use order

1. Upload `pi.pdf` as the manuscript PDF.
2. If the system asks for source files, upload `pi.tex`.
3. Use `SCHOLARONE_FMIC_METADATA.txt` to fill the online form.
4. Upload or paste `COVER_LETTER_FMIC.txt` if the system requests a cover letter.
5. Use `FMIC_SUGGESTED_REVIEWERS.txt` only if reviewer suggestions are requested and there is no conflict of interest.
